1. 적용 대상

본 방침은 maxchoe-dev가 개인적으로 개발·사용하는 도구(이하 "앱")에 적용됩니다. 앱의 사용자는 개발자 본인뿐입니다.

This policy applies to tools developed and used personally by maxchoe-dev ("the App"). The only user of the App is the developer.

2. 수집하는 정보

앱은 사용자가 명시적으로 허용한 범위(예: Google 계정 OAuth 권한)에서 본인 계정의 데이터에만 접근합니다. 그 외 개인정보는 수집하지 않습니다.

The App only accesses the user's own account data within explicitly granted scopes (e.g., Google OAuth). No other personal data is collected.

3. 이용 목적

접근한 데이터는 본인의 업무·학습 자동화 목적에만 사용되며, 광고·프로파일링·판매에 사용하지 않습니다.

Data is used solely for the user's own automation and never for advertising, profiling, or sale.

4. 제3자 제공

어떠한 데이터도 제3자에게 제공·공유하지 않습니다.

No data is shared with or transferred to third parties.

5. 보관 및 파기

데이터는 처리에 필요한 동안만 사용자 본인의 기기에 보관되며, 목적 달성 후 삭제합니다. 사용자는 언제든 Google 계정 권한 페이지에서 앱의 접근을 철회할 수 있습니다.

Data is stored only on the user's own device for as long as needed, then deleted. Access can be revoked anytime via Google Account permissions.

6. Google API 데이터 사용

Google API로부터 받은 정보의 사용 및 이전은 Limited Use 요건을 포함한 Google API Services User Data Policy를 준수합니다.

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
